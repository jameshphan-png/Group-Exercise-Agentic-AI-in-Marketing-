# Group-Exercise-Agentic-AI-in-Marketing-

How to run in Colab (using the Agentic AI in Marketing Notebook):
1. Ensure that you have the following Excel (dataset) files downloaded in the dev branch of this Github repository
   -Facebook.csv (Social)
   -Google.csv (Search)
   -Sprouts (Digital Marketing).csv (Display)

2. Upload the datasets in the Runtime Browser in Colab
   -Go to the "Files" tab on the left sidebar > upload all 3 Excel sheets
   -IMPORTANT: UPLOAD THESE FILES FIRST BEFORE RUNNING THE CODE TO ENSURE CONSISTENCY

3. Run the code "blocks" one-by-one (from #1 to #8)
   -Step 9 is optional, as it produces a summarized Excel file for future use (outside of Colab)

Assumptions:
The purpose of this AI agent is to create a comparison between the Agent's strategy and the baseline (when all 3 channels are being split evenly through 33-33-33 without change).
Its focus will vary on several outcomes, leading towards the total amount spent for the duration of 14 days - 1 month. (i.e. Click-through rate, impressions, etc).
In addition to this, it will also include certain rulesets such as guardrails, heuristics, etc to explore upon some aspects as to why one channel may impact superior performance (if that's the case).
Ultimately in the end, a rationale of why budget allocation exists for each channel (Social, Search, Display), to induce transparency and insights based on real-life simulation.

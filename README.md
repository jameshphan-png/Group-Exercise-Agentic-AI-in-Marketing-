# Group-Exercise-Agentic-AI-in-Marketing-

How to run in Colab (using the Agentic AI in Marketing Notebook):
1. Ensure that you have the following Excel (dataset) files downloaded in the dev branch of this Github repository
   -Facebook.csv
   -Google.csv
   -Sprouts (Digital Marketing).csv

2. Upload the datasets in the Runtime Browser in Colab
   -Go to the "Files" tab on the left sidebar > upload all 3 Excel sheets
   -IMPORTANT: UPLOAD THESE FILES FIRST BEFORE RUNNING THE CODE TO ENSURE CONSISTENCY

3. Run the code "blocks" one-by-one (from #1 to #8)
   -Step 9 is optional, as it produces a summarized Excel file for future use (outside of Colab)
